## Cómo se trabajó un PR

1. La historia de usuario pasa a **En Desarrollo** en Trello.
2. Se crea una rama `feature/<historia>` desde `main`.
3. Se sube la rama y se abre el PR con el resumen de lo implementado.
4. El pipeline de CI revisa tipos, migraciones, pruebas y build (desde el PR #9).
5. Con todo en verde se une a `main` y la tarjeta pasa a **Pruebas** o **Terminado**.
